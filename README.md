# Python 3 Jupyter Notebook

A collection of Jupyter Notebooks for learning and practicing Python 3.

This repository contains introductory Python examples and exercises organized into chapters. It is intended for beginners who want to learn Python interactively using Jupyter Notebook or JupyterLab.

## Requirements

You will need:

- Python 3
- JupyterLab or Jupyter Notebook

## Installation

Clone the repository:

    git clone <repository-url>

Move into the repository:

    cd Python3_Jupyter_Notebook

Install JupyterLab:

    python3 -m pip install jupyterlab

## Running the Notebooks

Start JupyterLab from the repository directory:

    python3 -m jupyterlab

JupyterLab should automatically open in your web browser.

Select one of the `.ipynb` files to begin.

## What is a `.ipynb` file?

`.ipynb` stands for **IPython Notebook**.

A Jupyter Notebook lets you combine:

- Python code
- Code output
- Explanations and notes
- Markdown
- Visualizations

You can run Python code one cell at a time, which makes notebooks especially useful for learning and experimentation.

## Suggested Order

If you are new to Python, start with:

    PythonIntro.ipynb

Then continue through the chapters in order:

    PythonIntroCh1.ipynb
    PythonIntroCh2.ipynb
    ...
    PythonIntroCh10.ipynb
